# ESP-Partybeleuchtung

## Beschreibung

Die LED auf dem ESP soll das Innere der Box beleuchten.

## Bisheriger Stand

Die Idee betrifft ausdrücklich die LED auf dem ESP; nicht ungefragt durch den NeoPixel-Stick ersetzen.

## Noch zu besprechen / prüfen

Welche Onboard-LED gemeint ist, gewünschter Effekt, Verhältnis zum Stick und Verhalten im Sleep klären.
