# Verteiler und Deckelverbindung

## Beschreibung

Stromverteilung oben/unten und lösbare Deckelverbindung konkretisieren.

## Bisheriger Stand

Zwei getrennte Verteiler für Versorgung/GND waren gemeint, keine elektrische Reihenschaltung. 3V3 und Boost-Rail dürfen nicht zusammengelegt werden.

## Noch zu besprechen / prüfen

Klemmen, Stecker, Aderzahl, Rail-Belegung, Strombelastbarkeit und Zugentlastung festlegen.
