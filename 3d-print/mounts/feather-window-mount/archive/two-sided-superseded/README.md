# Überholt: zweiseitiger CNC-Entwurf

`cnc-pocket.dxf` gehört zur früheren Innentasche. Der Nutzer hat ausdrücklich
nur Außenbearbeitung festgelegt. Diese Kontur NICHT fräsen. Die gültige Version
liegt im übergeordneten Ordner: `front_cnc.scad`, `cnc-opening.dxf` und
`cnc-rebate.dxf`, dazu Glaszuschnitt `cnc-glass.dxf`.
